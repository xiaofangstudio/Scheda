## 🔒 三条不妥协

### 1️⃣ 零常驻 —— 后台占用 = 0 KB

关闭窗口 = 进程**立刻完全退出**。不驻留托盘、不注册服务、不开机自启、不留后台线程。

「挂后台多少内存」的答案是 **0 KB**——不是「压到 10KB 以内」，是**根本不存在这个进程**。和 Chit 同一条铁律，永久成立。

### 2️⃣ 零联网 —— 不是流氓软件

这一条写在架构里，不是写在宣传语里：

- ❌ 不联网——没有遥测、没有崩溃上报、没有使用统计
- ❌ 不自动更新——装了什么版本就是什么版本
- ❌ 不捆绑——安装包里只有 Scheda 自己
- ❌ 不劫持系统——默认不抢 `.md` 关联，走 Windows 自带「默认应用」的官方路径，可逆、可干净卸载

### 3️⃣ 秒开 —— 冷启动 < 100 ms

原生程序，无 Electron、无 Tauri、无 .NET。看一个 Markdown 笔记不该比开一张图片慢。因为不常驻，「秒开」必须靠冷启动硬扛——这是 Scheda 整个技术选型围绕的唯一目标。

## ✨ 渲染要到位

查看器的本职是**忠实还原**，别人写的 MD 什么样，Scheda 就渲染成什么样：

- 📝 GFM 全支持：标题、列表、任务列表、表格、引用、分隔线
- 🎨 代码块语法高亮（常用语言开箱即用）
- 🔗 链接、图片（本地 + 相对路径）、脚注
- 🧮 行内 HTML 兜底渲染
- 🌓 跟随系统深色 / 浅色
- 🔍 `Ctrl+滚轮` 缩放、目录大纲一键跳转

**明确不做**：所见即所得编辑、双栏预览、导出 PDF、云同步——那是别的软件的事。

## ❓ 常见问题

**为什么不做编辑？**
编辑有 Chit 和别的编辑器。Scheda 把「看」这一件事做到极致，功能越克制，体积越小、启动越快。

**和 Typora 比呢？**
Typora 是编辑器，Scheda 是查看器——定位不同；而且 Scheda 免费开源、零联网。

**什么时候能用上？**
立项规格已定稿，进展看仓库动态。
