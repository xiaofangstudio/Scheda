## 🎨 界面

- **统一浅色**：全套 7 套预设都是浅色，不跟随系统深色，不出现任何深色面板
- **纯色底**：背景是干净的纯色，不做渐变、不撒光晕
- **磨砂 + 圆角**：阅读纸面、目录、设置卡片都是有厚度感的浮起卡片，靠一层极轻噪点 + 发丝边 + 柔和投影撑出"磨砂"质感
- **版心撑满窗口**：正文宽度跟着窗口走，不缩成中间一条窄缝；左侧目录栏只有在窗口够宽时才出现
- **排版**：H1–H6 分级、行内代码药丸底、引用块强调竖条、代码块语言条 + 复制、表格发丝分隔、任务列表勾选框、本地图片按真实比例渲染（远程图片一律跳过并标注"零联网"）
- **设置是一整页**：不是弹个小浮窗，是切到独立页面——左列 7 套预设主题 + 实时预览卡，右列强调色、7 个滑杆、三行字体、两个按钮，改什么都立刻生效
- **欢迎页有「最近打开」**：打开过的文件按时间倒序排着（最多 8 条，显示文件名和目录），点一下直接开；第一次用则是空状态提示。列表存在 `%APPDATA%\Scheda\settings.json` 的 `recent` 里，走人走文件自动剔除，不联网、不弹推荐
- **有图标**：多尺寸 `scheda.ico`（16/32/48/64/128/256）在标题栏、任务栏、Alt-Tab 里都是同一枚蓝底白页

## ⚙️ 改外观

设置页里拖滑杆就改，改动会写进 `%APPDATA%\Scheda\settings.json`。这个文件里除了 `theme` 和 `overrides`，还存着 `recent`（最近打开，最多 8 条），直接改也行。想批量改主题，直接编辑 JSON：

```json
{
  "name": "我的主题",
  "mode": "light",
  "bg": "#F7F8FA",
  "accent": "#0E8FB8",
  "accent2": "#5851D6",
  "text": "#1B2129",
  "muted": "#727C86",
  "radius": 18,
  "frost": 0.28,
  "font_size": 16,
  "line_height": 1.75,
  "para_gap": 14,
  "shadow": 0.22,
  "sheet_alpha": 0.94,
  "font_text": "Microsoft YaHei UI",
  "font_mono": "Cascadia Mono",
  "code_bg": "#EEF3F8"
}
```

`%APPDATA%\Scheda\themes\*.json` 里放任意多个主题文件，重启后在设置页的主题列表里就能看到它们（设置页底部的"打开主题文件夹"直接带你去）。

## 🔒 三条不妥协

### 1️⃣ 零常驻 —— 后台占用 = 0 KB

关闭窗口 = 进程**立刻完全退出**。不驻留托盘、不注册服务、不开机自启、不留后台线程。

就算窗口开着：欢迎页闲下来 1.5 s 后会把工作集**还给系统**（任务管理器里几乎归零），最小化时直接丢掉排版和背景缓存，再展开重新排——不会占着不放。

### 2️⃣ 零联网 —— 不是流氓软件

- ❌ 不联网——没有遥测、没有崩溃上报、没有使用统计
- ❌ 不自动更新——装了什么版本就是什么版本
- ❌ 不捆绑——只有一个 exe（外加一枚 `scheda.ico`）
- ❌ 不劫持系统——默认不抢 `.md` 关联

### 3️⃣ 秒开 —— 冷启动 < 100 ms

原生程序，无 Electron、无 Tauri、无 .NET。技术栈是 **Rust + Direct2D + DirectWrite + DWM**，窗口是自己画的，连标题栏都没交给系统。实测点开图标到窗口出来 **47–64 ms**（首次冷读约 123 ms）。

```powershell
cd D:\20533\deskbox\fangwork\Scheda
```

### ⚠️ 本机开工约定（对 AI / 协作方）

- **虚拟桌面只借来临时干活**：开出来看一眼功能、截张图，事情一做完**立刻关掉**。这台机器上跑着远程桌面，虚拟桌面留着一个就会撞上。
- 截图统一走 `tools\shot.ps1`（`PrintWindow` 抓窗口，不靠屏幕截图，不会因为窗口被挡而失败）。
- 验收完把 `Get-Process scheda` 清掉，别留后台进程干扰下一次测量。

## ❓ 常见问题

**为什么不做编辑？**
编辑有 Chit 和别的编辑器。Scheda 把"看"这一件事做到极致，功能越克制，体积越小、启动越快。

**为什么不做深色？**
刻意的。看清一版文字，浅色纸面 + 纯色底最稳，也不用为两套配色各调一遍对比度。
