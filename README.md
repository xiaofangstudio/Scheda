## 🎨 界面

- **浅色为主，可切深色**：7 套预设本身全是浅色（不跟随系统），设置页主题卡右上角有「浅色 / 深色」两枚药丸，点一下就在当前预设上推一份深色版——强调色和排版不动，只换底、纸、字、代码配色；默认仍是浅色
- **默认壁纸 + 可控背景**：欢迎页/阅读页底下一层是内置的那张蓝奶油抽象壁纸（编进 exe，不落地成文件），上面盖一层薄雾保证文字可读；设置页字体卡的「背景」行点一下开 / 关，右边「换图…」挑本机任意图片，`settings.json` 里记成 `bg`（`default` / `none` / 绝对路径）
- **真磨砂玻璃（不染色）**：每块面板都把身后那层壁纸按 1/8 三级降采样磨成模糊图，再按圆角形状抠出来；盖上去的涂层只有纯白/纯黑两种「无色玻璃浆」（深浅随明暗主题切换），零色相——颜色全部来自被磨过的壁纸本身，不是给玻璃刷一层蓝白漆。配细噪点、上沿高光、下沿反光、内阴影撑出厚度。窗口一动、换壁纸、换主题，模糊图重做一次；磨砂滑杆管颗粒浓度
- **滚动条能拖**：正文右侧那条细滚动条、目录面板自己的滚动条都能按、能拖、能点轨道跳转；鼠标滚轮落在目录面板里就滚目录，落在正文就滚正文；目录条目多到装不下时自动出目录滚动条
- **版心撑满窗口**：正文宽度跟着窗口走，不缩成中间一条窄缝；左侧目录栏在窗口够宽时出现（逻辑宽 ≥ 860 就出）
- **目录会跟着读**：点目录里的章节直接跳到对应位置（瞬时到位，不是慢吞吞滑过去）；右边正文滚到哪，左边就把当前章节高亮并自动滚进可视区，长文档也不会「高亮在屏幕外」
- **窗口规矩**：先藏着把尺寸和位置算好再显示，开窗只出现一次、不抖不拉长；换 DPI 只换绘制比例、不动窗口大小；**永不置顶**（别人的窗口能正常盖上来）；八条边 + 四个角都能拖（边 8pt、角 14pt）；标题栏拖动是自己实现的（不依赖系统移动循环，双击标题栏最大化 / 还原）；窗口最大尺寸被钉死在工作区，永远拉不出屏幕外，也就不会出现"拖不动、关不掉"
- **只读 / 编辑**：主题左边那枚按钮，只读时是闭合的挂锁（带钥匙孔），点一下变成铅笔、进源码编辑——等宽字体、闪烁光标、`Ctrl+S` 存盘。**光标会记位置**：退出编辑时记下光标和滚动位置，再点回来还在原处；上下键按「想去的列」走，经过短行不会把列号吃掉、光标不会一路往左漂
- **点图看大图**：正文里的本地图片点一下就进图片查看器，滚轮缩放（20%–800%）、按住拖动平移、`适应窗口` / `原始大小` / `复制`（Ctrl+C 也能复制到剪贴板）/ `Esc` 关闭
- **中文 / English**：设置页右上角语言药丸，整个界面文案即时切换（源串是中文，英文查表），主题预设名也跟着翻（Aurora / Rime / Ink Jade / Neon / Paper / Dawn），下次启动记住选择
- **排版**：H1–H6 分级、行内代码药丸底、引用块强调竖条、代码块语言条 + 复制、表格发丝分隔、任务列表勾选框、本地图片按真实比例渲染（远程图片一律跳过并标注"零联网"）
- **设置是一整页**：不是弹个小浮窗，是切到独立页面——左列 7 套预设主题 + 实时预览卡 + 浅色/深色药丸，右列强调色、7 个滑杆、字体四行（界面/正文/代码/背景）、换图与关联按钮，改什么都立刻生效
- **欢迎页：名字在左上角，两张一样大的卡左右排**：`Scheda` 从正中挪到左边（图标 + 名字 + 一行说明），整块「名字 + 两张卡」在窗口里上下居中，不再头重脚轻；下面两片等宽等高的磨砂玻璃卡——左边是「把 .md 文件拖进来 / 按 Ctrl+O」加四枚快捷键药丸，右边是「最近打开」，最多 24 条、文件名 + 目录，**列表装不下时可以直接滚**（滚轮落在右卡里就滚右卡，带细滚动条），点一下直接开；第一次用则是空状态提示。列表存在 `%APPDATA%\Scheda\settings.json` 的 `recent` 里，走人走文件自动剔除，不联网、不弹推荐
- **有图标**：多尺寸 `scheda.ico`（16/32/48/64/128/256）在标题栏、任务栏、Alt-Tab 里都是同一枚蓝底白页
- **`.md` 有自己的文档图标**：`md.ico`（白纸 + 折角 + 蓝色「MD」）专门给 Markdown 用；设置页右上角「设为默认 .md 打开方式」会把 `Scheda.md` 和 `Applications\scheda.exe` 两个 ProgID 登记到 `HKCU\Software\Classes`（只写当前用户，随时可删），之后在资源管理器里选 Scheda 当默认，`.md` 文件显示的就是这枚纸页图标，不再是那个 exe 壳子。也可以命令行一键登记：`Scheda.exe --register-md`

## ⚙️ 改外观

设置页里拖滑杆就改，改动会写进 `%APPDATA%\Scheda\settings.json`。这个文件里除了 `theme` 和 `overrides`，还存着 `recent`（最近打开，最多 24 条），直接改也行。想批量改主题，直接编辑 JSON：

```json
{
  "name": "我的主题",
  "mode": "light",
  "bg": "#F7F8FA",
  "accent": "#0E8FB8",
  "accent2": "#5851D6",
  "text": "#1B2129",
  "muted": "#727C86",
  "radius": 18,
  "frost": 0.28,
  "font_size": 16,
  "line_height": 1.75,
  "para_gap": 14,
  "shadow": 0.22,
  "sheet_alpha": 0.94,
  "font_text": "Microsoft YaHei UI",
  "font_mono": "Cascadia Mono",
  "code_bg": "#EEF3F8"
}
```

`%APPDATA%\Scheda\themes\*.json` 里放任意多个主题文件，重启后在设置页的主题列表里就能看到它们（设置页底部的"打开主题文件夹"直接带你去）。

## 🔒 三条不妥协

### 1️⃣ 零常驻 —— 后台占用 = 0 KB

关闭窗口 = 进程**立刻完全退出**。不驻留托盘、不注册服务、不开机自启、不留后台线程。

就算窗口开着：欢迎页闲下来 1.5 s 后会把工作集**还给系统**（任务管理器里几乎归零），最小化时直接丢掉排版和背景缓存，再展开重新排——不会占着不放。

### 2️⃣ 零联网 —— 不是流氓软件

- ❌ 不联网——没有遥测、没有崩溃上报、没有使用统计
- ❌ 不自动更新——装了什么版本就是什么版本
- ❌ 不捆绑——只有一个 exe（外加一枚 `scheda.ico`）
- ❌ 不劫持系统——`.md` 关联不会偷偷改；要登记得你自己在设置页点「设为默认 .md 打开方式」，而且只写 `HKCU`，删掉那几个键就干净了

### 3️⃣ 秒开 —— 冷启动 < 100 ms

原生程序，无 Electron、无 Tauri、无 .NET。技术栈是 **Rust + Direct2D + DirectWrite + DWM**，窗口是自己画的，连标题栏都没交给系统。实测点开图标到窗口出来 **55–120 ms**（首次冷读约 120 ms；机器在编译别的东西时会抖）。内置壁纸是 1280×720 的 JPEG（48 KB），WIC 解码一次就缓存，换背景才重解。

## 🛠 构建

```powershell
cd D:\20533\deskbox\fangwork\Scheda
cargo build --release
# 产物：target\release\scheda.exe（默认壁纸是从 assets\背景.jpg include_bytes 进来的，换图要改文件再重编）
.\target\release\scheda.exe .\test\demo.md
.\target\release\scheda.exe --register-md   # 静默登记 .md 关联
```

图标生成：`tools\make-icon.ps1`（应用图标）、`tools\make-md-icon.ps1`（`.md` 文档图标，输出 `dist\md.ico` + `assets\md.ico`）。

依赖只有 `windows`（Direct2D / DirectWrite / DWM 绑定）、`pulldown-cmark`、`serde_json`、`windows-numerics`。

### ⚠️ 本机开工约定（对 AI / 协作方）

- **虚拟桌面只借来临时干活**：开出来看一眼功能、截张图，事情一做完**立刻关掉**。这台机器上跑着远程桌面，虚拟桌面留着一个就会撞上。
- 截图统一走 `tools\shot.ps1`（`PrintWindow` 抓窗口，不靠屏幕截图，不会因为窗口被挡而失败）。
- 验收完把 `Get-Process scheda` 清掉，别留后台进程干扰下一次测量。

## ❓ 常见问题

**它不是只能看吗？**
看是主业，改是副业。默认停在只读，锁着就不会手滑改掉别人的文档；真要在路上改两行，点一下标题栏那枚锁就进源码编辑，改完 `Ctrl+S`，锁回去继续读。不做富文本、不做 WYSIWYG——那才是 Chit 的活。

**为什么默认不做深色？**
看清一版文字，浅色纸面最稳。但要做还是做了：设置页主题卡右上角点「深色」，就在当前预设上推一份深色配色，只换中性色、强调色和代码 token 都留着，默认仍是浅色。

**为什么 .md 以前显示成 exe 图标？**
因为程序是绿色单文件，exe 里没塞图标资源，Windows 就拿了默认壳子。现在给 Markdown 配了独立的 `md.ico`，并把 `Scheda.md` / `Applications\scheda.exe` 两个 ProgID 都指到它——前提是你在设置页点一下「设为默认 .md 打开方式」或在资源管理器「打开方式」里选 Scheda。
